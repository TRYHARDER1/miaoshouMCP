# M5.3 独立安全交付修正报告

基线 `68064ae`，2026-11-08。用户在安全审查后明确批准实施。代码和技术测试已完成。

## 修正

新增 `product_image_export_muse_delivery(batchId)`，从已发布的内部 v1 包生成独立交付目录。manifest 使用专用 DTO 白名单，仅包含交付版本/策略、不透明 deliveryId、Singapore/English，以及 assetId、相对图片名、角色、处理要求和包内顺序。新 Prompt 只由白名单生成，不含原 URL、SKU Key、references、snapshot/plan/batch/job 内部 ID、绝对路径或结果链接。

图片只从已核对本地原件复制，不联网，不占 M5.2 任务租期，不创建 job 或改结果登记。每个 assetId 原值不变，本地全部关联仍保留。候选主图不升级为正式主图，SKU 变体只按 assetId 指示保留外观。

旧内部 Prompt 构造器文本/VERSION、v1 包、已有链接、数据库结构都不因本修正改变。旧 export 工具的描述明确提示内部用途；README 指导只交付独立安全目录。安全投影由既有 job+策略确定标识，使用私有 staging 原子发布；已有正确目录幂等复用，未知文件/损坏明确拒绝，不覆盖。

## 验证

安全修正先单独完整构建：135 项通过（原 129、新增 6），失败/错误/跳过均为 0。测试包含 1/4 张原件副本，根和每资产 DTO 的精确字段白名单，源签名/令牌哨兵不外发，多 SKU 关联本地保留，候选角色保留，旧包摘要和重复导出不变，并发同一目录、未知文件拒绝和无内部包时不下载。
