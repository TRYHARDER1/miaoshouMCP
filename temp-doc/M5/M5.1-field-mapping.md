## URL、HTML 与指针

仅本地语法校验绝对 HTTP(S) URL 且有 host；含 userInfo 的 URL 不接受。不联网确认可达性，不移除参数或规范化大小写。非法非空 URL 保留原值及引用，资产状态 INVALID_URL；错误信息只含路径和错误码。

HTML src 的值采用 Jsoup 解析后的属性值，实体 `&amp;` 按 HTML 语义解析为 `&`；保留原 HTML 字符串，不重新序列化写回。缺失、null、空白 URL 计入 skippedEmptyReferences。

所有 sourcePath 为相对商品对象的 RFC 6901 指针；HTML 内部位置额外使用 htmlImageIndex。指针 token 的 `~` 转义为 `~0`、`/` 转义为 `~1`，分号保持原值。真实 SKU 图片路径使用数组索引，SKU Map Key 作为原始元数据保留，不需要错误地把分号转义。
