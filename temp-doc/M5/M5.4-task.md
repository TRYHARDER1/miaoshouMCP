## T02：追加两张专用表与事务 Repository

- 目标：数据库唯一、外键、CAS、状态事件原子性；依赖 T01。
- 阅读：schema.sql、MuseJobMapper、ImageBatchMapper、现有 TransactionTemplate 用法。
- 新增 Java：MuseProcessedResultMapper，必要的专用 SchemaVerifier（只核对已批准表结构）。
- 修改 Java：无既有业务类；拟修改 schema.sql 仅追加批准 DDL。新增表 ms_muse_processed_result、ms_muse_processed_event。
- 涉及字段：技术设计完整 DDL 的所有字段，特别 PK(job_id,asset_id)、source_url_hash、original_sha256、status、row_version、attempt_no、retry_count、token/lease、路径/元数据、错误及时间；事件外键/唯一版本与索引。
- 落库：首次处理请求建 PENDING；每次状态/所有权变化更新当前行并插事件。
- 事务/并发：先写专用表取得 SQLite 写锁后再读；CAS 命中必须为 1；状态与事件同提交，心跳不复制 URL。
- 异常：外键/唯一/SQL/提交失败整笔回滚并脱敏；已有同名不兼容表明确拒绝，不偷偷 ALTER。
- 验收/测试：真实 SQLite 复合外键、唯一约束、NULL 不能绕过 VALIDATED 必填约束、事件回滚、两进程竞争；旧表 DDL 和全部原数据保持。迁移仅在批准后执行并备份。

## T06：专用文件发布与完整凭据

- 目标：原件不变、每资产独立、可恢复且不覆盖成品；依赖 T03–T05。
- 阅读：MusePackageFiles、M5.3 旧包校验/目录、已批准存储根策略。
- 新增 Java：MuseProcessedFiles；修改 Java：无，追加 processed 子目录不改旧文件。

- 事务/并发：独占 token 临时目录，CREATE_NEW/NOFOLLOW，原子移动整资产目录；目录存在先核验，不能直接 REPLACE_EXISTING。
- 异常：越界/符号链接/Windows 重解析点、原子移动不支持、磁盘不足/权限、同名冲突均保留证据并失败；不递归删除未知文件。

## T07：单资产编排、幂等与批内部分成功

- 目标：完成从登记到本地技术结果的主流程；依赖 T02–T06。
- 阅读：ImageBatchService 的事务模式、MuseJobService 发布恢复模式，但不调用其修改流程。
- 新增 Java：MuseProcessedImageService；修改 Java：无既有业务类。
- 表/字段：写两张新表的状态、token/version/lease、重试及阶段时间、元数据与事件；读旧表但不回写。
- 落库：PENDING→预约→DOWNLOADED→VALIDATING→原子发布后 VALIDATED；失败写阶段和固定原因。每资产独立，不把整个批次放在一个跨网络事务里。
- 事务/并发：短事务先写后读，CAS+唯一键；下载/解码释放连接。发布前再核源和控制状态；失败不影响其他资产，旧 worker 不能提交。
- 异常：失败类别、可重试与文件冲突分别处理；不更换 URL，不覆盖成品，显式重试计数才递增。
- 验收/测试：同资产重复零重复联网、并发双进程、多商品/快照隔离、部分成功、源漂移、租期失效、SQL/文件故障；结果登记仍 LINK_REGISTERED/false。

## T08：本地恢复、审计和进度

- 目标：进程退出后继续可信本地阶段，不永久卡死或重复网络；依赖 T07。
- 阅读：ImageBatchRecovery 的阶段边界、MuseJobService 历史恢复测试、当前新表事件。
- 新增 Java：MuseProcessedRecovery；修改 Java：仅 T07 新服务增加恢复/进度入口，不修改 ImageBatchRecovery。
- 表/字段：本阶段过期 lease、stage、row_version、attempt_no、token、error、阶段时间与事件；读本地 receipt。
- 落库/事务：有界启动元数据扫描，本地完整证据核查后短事务补记；新 owner 新 token，明确恢复事件。完整文件不重下，半文件需明确网络重试。
- 并发：恢复也受 CAS 保护，不能覆盖新 token；合法发布目录优先核查，再决定是否分配新尝试。
- 异常：失效/缺少/外来凭据、文件损坏、已有更新尝试时拒绝；不删除原图或受损成品，不把“超时”当成外部工作已停止。
- 验收/测试：在所有持久化/下载/校验/发布边界杀独立进程；到期回收、本地续验、提交前退出补记、失效文件查询、状态事件顺序、恢复无自动网络。既有 M5.2 启动动作单独建立基线。
