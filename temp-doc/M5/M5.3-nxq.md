# M5.3 需求

读取已存在的 M5.2 批次，导出 1–4 个不同资产的 Muse 人工任务包：真实原图文件、完整 manifest、英文 Prompt、全部引用/SKU Key、批次上下文。保留 UNCLASSIFIED 和首图候选，不修改提取规则或资产分配。

目标市场新加坡，目标语言 English。每个 assetId 独立生成结果，翻译中文为自然英文，保持颜色、形状、材质、数量、配件、结构及必要品牌，不虚构参数，不合并图片，失败明确报告。

同批次固定一个 jobId、版本 1。重复导出复用，版本不匹配明确冲突；不自动删除旧包或生成新版本。导出失败可安全重试。人工交接不领取 M5.2 任务、不改变其租期或状态。

结果按 batchId、assetId、downloadUrl 登记，每次 1–4 条，允许部分提交；相同资产和原链接幂等，不同链接冲突；同一结果 URL 不允许映射多个资产。登记状态仅 LINK_REGISTERED，downloadVerified=false，不能视为质量合格或上传成功。重启后任务包、交接状态及部分结果保留。

本阶段新增安全原图获取是任务包必要依赖，安全分析见技术设计。只读取快照原图，不抓取 Muse 网页、不调用 Muse、不下载结果图片、不上传、不修改商品/草稿、不发布，不进入 M5.4。

验收包含正式指令 20 项场景、并发/回滚/中断恢复、下载安全边界、原 M5.1/M5.2 数据不变性及全部回归。
