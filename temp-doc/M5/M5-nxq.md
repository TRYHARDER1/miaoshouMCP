# M5 图片阶段需求

采用人工向 Muse 提交任务包的方案 A；未来 MCP 接收结果链接后再负责下载校验及上传。主图、副图、SKU 图和详情图均纳入完整 M5 范围。

Muse 每批最多 4 个不同图片资产，不复制图片凑数；不足 4 张的能力留待对应阶段验证。

已完成 M5.1 图片资产提取与分类，本次用户授权实现 M5.2 持久化批次调度。清单必须区分原始 URL 对应的唯一资产与多个使用位置；保留原始关联、数组顺序、SKU ID 及原 Map Key；同一快照重复提取的资产 ID 和结果稳定。

M5.1 只读取本地已有快照，不添加数据库表，不调用任何外部服务，不修改商品或草稿。发现字段结构与计划不一致时，记录事实和影响，停止相关实现并反馈。主图和副图没有确认规则时使用 UNCLASSIFIED 与候选标识。

M5.2 持久化分配和任务状态，保证同一快照重复及并发创建不重复，支持暂停/恢复/取消/失败重试与租期超时恢复。详见 M5.2-nxq.md。后续为 M5.3 Muse 任务包、M5.4 结果链接管理、M5.5 下载及质量检查、M5.6 妙手上传、M5.7 图片替换、M5.8 端到端验收。M5.2 验收后停止，后续阶段需要新的任务指示。
